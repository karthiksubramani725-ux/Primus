README - PRIMUS x NFS MW05 (Simplified Version)

How it works:
1. This Python script simulates Primus watching your driving style.
2. If you're driving recklessly (fast + off-road), it logs an action.
3. You can later connect this to Cheat Engine or VltEd to change cop behavior in-game.

To Use:
- Open this script using Python (double-click or run in terminal).
- Modify 'offroad_time' and 'player_speed' to simulate different driving styles.
- Watch the output in the terminal and in 'primus_action.txt'.

No coding needed for now. This is your starting point!
